# TheraValue
Initial research application. Python 3.11 recommended.

Run `pip install -r requirements.txt` then `streamlit run app.py`.
Deploy app.py via Streamlit Community Cloud. Include the .streamlit folder.
Live PubMed retrieval requires internet access. No API key is required for the limited search workflow. No AI extraction or insurance API is connected yet. Do not enter patient identifiers. Cost inputs are user-attested, not independently verified by software. Published SURPASS-2 values are from PMID 34170647. Session reports are not persistent.
